# Demo image sources

The four product photos in this prototype were downloaded from publicly accessible retailer pages discovered through image search. They are placeholders for visual prototyping only and should be replaced with ComfyNest-owned or appropriately licensed catalogue photography before commercial use.

- `cloud-beanbag.jpg`: Futon Store Memphis
- `nest-chair.jpg`: Noon
- `weighted-blanket.jpg`: Walmart
- `lounge-pouf.png`: Chic Homz

`og.png` is an original ComfyNest social-preview image generated for this project.

Products imported through the admin panel keep the image URLs supplied in the CSV. Those images are not copied into this project; the catalogue owner is responsible for confirming usage rights and availability.
